# Login intro music

The login screen looks for an audio file at `assets/login-theme.mp3` and tries to autoplay it when the page opens. Browsers may require a user gesture before allowing sound; the screen provides a play button and also retries on the first interaction.

Add a track here only if you own it or have permission to redistribute it. Keep this path exactly `assets/login-theme.mp3`. The actual audio binary is intentionally not included in this public repository.
