# ⚡ چت آنلاین

### یک اتاق چت فارسی با WebRTC، بازی و رابط شیشه‌ای

**[▶ دمو زنده](https://arsam92.github.io/chat/)**

این پروژه یک فایل HTML شامل رابط کاربری، منطق چت و بازی‌های سبک چندنفره است.

## ویژگی‌ها

- پیام متنی، ریپلای، واکنش و حذف پیام
- ارسال عکس، استیکر، ویس و نظرسنجی
- پیام خصوصی بین دو همتا
- فهرست کاربران و وضعیت تایپ
- سنگ‌کاغذقیچی، دوز، اسم‌فامیل و UNO
- تم‌های مختلف، تنظیمات فونت و پروفایل
- رابط فارسی RTL با طراحی سازگارتر با موبایل
- ورود و خروج پیام با انیمیشن‌های کوتاه‌تر و احترام به تنظیمات کاهش حرکت سیستم
- smoke test خودکار برای بررسی نحو JavaScript و چند رگرسیون مهم

## اجرا

فایل `index.html` را در مرورگر باز کن یا سرور محلی اجرا کن:

```bash
python3 -m http.server 8000
```

بعد `http://localhost:8000` را باز کن. برای دسترسی به میکروفون و بعضی قابلیت‌های مرورگر از HTTPS یا localhost استفاده کن.

## تکنولوژی

- HTML، CSS و JavaScript خام
- [PeerJS](https://peerjs.com/) برای signaling و اتصال WebRTC
- فونت Vazirmatn

## محدودیت‌های مهم

- پروژه بک‌اند اختصاصی ندارد، اما برای کشف همتاها از سرویس سیگنال‌دهی PeerJS استفاده می‌کند.
- پیام‌ها در دیتابیس مرکزی ذخیره نمی‌شوند. کاربری که تازه وارد می‌شود، به‌طور خودکار تاریخچه پیام‌های قبل را دریافت نمی‌کند.
- این پروژه برای چت دوستانه و سرگرمی ساخته شده؛ چون بازی‌ها و حالت‌ها سمت کلاینت هستند، برای رقابت حساس یا اطلاعات محرمانه به معماری سرورمحور نیاز است.
- نسخه فعلی جایگزین یک سرویس پیام‌رسان با مدیریت حساب، ذخیره‌سازی پایدار و تعدیل محتوا نیست.

## بررسی خودکار

تست سبک را می‌توان با Node.js 20 اجرا کرد:

```bash
node tests/smoke-check.mjs
```

تست‌ها syntax و چند شرط اصلی را بررسی می‌کنند؛ اتصال WebRTC، مجوز میکروفون و تعاملات واقعی باید جداگانه در مرورگر آزمایش شوند.
