# چت آنلاین 💬

**یک چت peer-to-peer کامل داخل یک فایل HTML.**

بدون سرور، بدون ثبت‌نام، بدون نصب. فقط فایل را باز کن و با دوستانت چت کن.

> WebRTC + PeerJS · RTL فارسی · Glassmorphism · بازی UNO داخل چت

---

## ▶ اجرا

1. فایل [`index.html`](index.html) را دانلود کن  
2. با مرورگر (Chrome / Firefox / Edge) بازش کن  
3. اسم بذار و وارد شو

یا مستقیم از GitHub Pages (اگر فعال باشد) باز کن.

```bash
# یا لوکال با سرور ساده
python3 -m http.server 8000
# سپس http://localhost:8000
```

## ✨ امکانات

| دسته | قابلیت‌ها |
|------|-----------|
| **چت** | پیام متنی، ریپلای، پین، حذف، فوروارد |
| **رسانه** | ایموجی، استیکر، عکس/فایل، پیام صوتی (ضبط با میکروفون) |
| **کاربر** | لیست آنلاین، وضعیت آنلاین/آفلاین، پروفایل قابل ویرایش |
| **خصوصی** | پیام خصوصی (PM) در پنجره جدا |
| **بازی** | **UNO** کامل داخل چت (دعوت، نوبت، کارت وحشی، +۲، اسکیپ) |
| **ظاهر** | تم روشن/تاریک، افکت Aurora، Neon Glow، انیمیشن‌های فنری |
| **فنی** | تک‌فایل، PeerJS (WebRTC)، بدون بک‌اند |

---

## 🛠 تکنولوژی

- **HTML + CSS + Vanilla JS** (یک فایل ~۱۶۰ KB)
- **[PeerJS](https://peerjs.com/)** برای ارتباط peer-to-peer روی WebRTC
- فونت **Vazirmatn**
- بدون فریم‌ورک، بدون باندلر، بدون سرور خودی

پیام‌ها و اتصال مستقیم بین مرورگرها رد و بدل می‌شوند. سرور PeerJS فقط برای signaling استفاده می‌شود.

---

## 🎮 بازی UNO

از منوی کاربر می‌تونی دوستت را به UNO دعوت کنی:

- دست کارت، نوبت، کارت‌های رنگی و وحشی
- اسکیپ، +۲، ریورس
- انیمیشن پرواز کارت و کانفتی برد
- همه منطق روی هر دو کلاینت همگام می‌شود

## نکات

- برای پیام صوتی و بعضی قابلیت‌ها به HTTPS یا localhost نیاز داری (محدودیت مرورگر).
- چون P2P است، هر دو طرف باید آنلاین باشند و Peer ID درست رد و بدل شود.
- داده‌ها در مرورگر می‌مانند؛ سرور مرکزی برای ذخیره پیام وجود ندارد.
