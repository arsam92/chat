## ▶ اجرا

### آنلاین (پیشنهادی)
فقط برو اینجا:

**→ [arsam92.github.io/chat](https://arsam92.github.io/chat/)**

### آفلاین / لوکال

1. فایل [`index.html`](index.html) را دانلود کن  
2. با مرورگر بازش کن (یا با سرور محلی):

```bash
python3 -m http.server 8000
# سپس http://localhost:8000
```

> برای پیام صوتی و بعضی قابلیت‌ها بهتر است از HTTPS یا `localhost` استفاده کنی.

## 🎮 بازی‌های داخل چت

از منوی کاربر روی هر نفر می‌تونی دعوت کنی:

- **UNO** — دست کارت، نوبت، کارت وحشی، +۲، اسکیپ، کانفتی برد
- **سنگ کاغذ قیچی** — سریع و رقابتی
- **دوز (Tic-Tac-Toe)** — کلاسیک
- **اسم فامیل** — بازی گروهی فارسی

همه منطق سمت کلاینت همگام می‌شود. سرور لازم نیست.

## 🛠 تکنولوژی

- **HTML + CSS + Vanilla JS** — بدون فریم‌ورک، بدون باندلر
- **[PeerJS](https://peerjs.com/)** — signaling و اتصال WebRTC
- فونت **Vazirmatn**
- پیام‌ها peer-to-peer؛ هیچ سرور مرکزی پیام‌ها را نگه نمی‌دارد

```
chat/
└── index.html   ← UI + منطق + بازی‌ها + استایل
```

## نکات فنی

- چون P2P است، هر دو طرف باید آنلاین باشند.
- داده‌ها فقط در مرورگر می‌مانند (localStorage برای تنظیمات).
- برای میکروفون و بعضی APIها به context امن (HTTPS / localhost) نیاز است.
